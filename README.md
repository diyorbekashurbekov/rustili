# Алматы — город у гор

Проект по русскому языку.
Тема: **Географическое положение города. Окружающая природа: реки, горы, озёра. Экология города.**

Автор: Диярбек Ашурбеков

## Что внутри

Один сайт-презентация с прокруткой, где каждый раздел — это фотография на весь экран,
а текст появляется поверх неё:

| № | Раздел | Что показывает |
|---|--------|----------------|
| 1 | Алматы | влетаем сквозь буквы названия в фотографию гор |
| 2 | Географическое положение | спуск из космоса к городу, высотомер 400 км → 1,1 км |
| 3 | Горы | спуск с пика Талгар (4979 м) до Кок-Тобе (1100 м) |
| 4 | Реки | кадр за кадром: ледник → ущелье → город |
| 5 | Озёра | горизонтальная галерея: БАО, Кольсай, Каинды, Иссык |
| 6 | Экология | смог стирается со снимка, небо становится чистым |
| 7 | Причина и решение | почему город в котловине и что делает воздух чище |
| 8 | Игры | «Где это?», викторина, «Найди пару», «Полезно или вредно?» |
| 9 | Словарь | карточки с новыми словами урока |

## Как открыть

Скачать репозиторий и открыть `index.html` в браузере.
Папка `images` должна лежать рядом с `index.html` — иначе фотографии не покажутся.

## Фотографии

Все снимки взяты с [Wikimedia Commons](https://commons.wikimedia.org) под свободными
лицензиями (CC0, CC BY, CC BY-SA, Public domain). Авторы каждого снимка указаны
внизу сайта со ссылкой на оригинал.

## Технологии

- HTML, CSS, JavaScript — без сборки, один файл `index.html`
- [GSAP + ScrollTrigger](https://gsap.com) — анимации по прокрутке
- [Lenis](https://lenis.darkroom.engineering) — плавная прокрутка

Если интернет недоступен и библиотеки не загрузятся, сайт всё равно откроется:
фотографии и текст останутся на месте, пропадут только анимации.
